# fitdash Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A personal Android app that reads every Health Connect data type and shows it on one long, animated page with a "living orb" hero (readiness in the morning, steps in the evening).

**Architecture:** `health/` is the only code touching Health Connect and turns records into a plain `HealthSnapshot`. `metrics/` is pure Kotlin (no Android) that turns a snapshot plus the current time into `TodayData` (scores, summaries, card order). `ui/` is Compose: a ViewModel exposes `TodayUiState`, and `TodayScreen` renders the hero orb and cards. No database; every open re-reads Health Connect.

**Tech Stack:** Kotlin 2.4.20, AGP 9.4.0 (built-in Kotlin), Jetpack Compose (BOM 2026.09.00, Material 3), `androidx.health.connect:connect-client:1.1.0`, lifecycle 2.11.0, coroutines 1.11.0, JUnit 4.

**Spec:** `docs/superpowers/specs/2026-10-11-fitdash-design.md`

## Global Constraints

- Package and applicationId: `app.fitdash`. minSdk 26, targetSdk 36, compileSdk 37 (same as Postbaaz).
- Health Connect only. No Fitbit Web API, no Bluetooth, no network, no server, no database, no WorkManager.
- Dark UI only. Background `#0A0A0D`, cards `#15151B`.
- Orb colour: traffic light, red `rgb(229,72,77)` at 0 → amber `rgb(245,176,65)` at 50 → green `rgb(61,220,151)` at 100, linear per channel.
- Breathing cycle: 7000 ms at score ≤ 15, 4000 ms at score ≥ 98, linear between.
- Hero switches from readiness to activity at 16:00 local time (hour ≥ 16).
- Baseline = median of the 30 days before the date, excluding the date itself. Calibrating until 7 nights of data.
- Readiness weights HRV 40%, resting HR 30%, sleep 30%; mapping and bands exactly as in the spec table. All tuning numbers live in `metrics/Tuning.kt`.
- Step goal fixed at 9,000. No settings screen.
- Cycle-tracking and sexual-activity record types are not read in v1 (categorical data with no numeric card; deliberately left out of "every type").
- All dates are bucketed in the device's local time zone (Mayur is on IST, UTC+5:30).
- Commit messages: plain, no `Co-Authored-By` or any AI attribution trailer.

## Review Focus

1. **IST date bucketing:** a sample at 01:30 IST belongs to that IST date, not the previous UTC date. Pinned in Task 2 (`dailyMean buckets by local date not UTC`).
2. **Baseline must exclude the day being scored:** today's spike must not pull its own baseline. Pinned in Task 2 (`baseline excludes today and anything older than 30 days`).
3. **Afternoon nap vs night's sleep:** "last night" is the longest session ending on the date, so a 40-minute nap must not replace it. Pinned in Task 3 (`nightEnding picks the longest session, not a nap`).
4. **Steps double-counted when the phone and the Fitbit both write steps:** totals must come from Health Connect's aggregate API (which de-duplicates), never from summing raw `StepsRecord`s. Implemented in Task 7 and checked in Task 10 step 4 against the Fitbit app's own count.
5. **16:00 boundary and missing inputs:** 15:59 shows readiness, 16:00 shows activity; a missing HRV re-weights the other components instead of scoring zero. Pinned in Task 6 (`hero switches at exactly 16:00`) and Task 4 (`missing HRV re-weights`).

```kotlin
package app.fitdash

import app.fitdash.health.HealthSnapshot
import app.fitdash.health.Sample
import app.fitdash.health.SleepSession
import app.fitdash.health.SleepStage
import app.fitdash.health.StageType
import java.time.Instant
import java.time.LocalDate
import java.time.LocalDateTime
import java.time.ZoneId

val IST: ZoneId = ZoneId.of("Asia/Kolkata")
val TODAY: LocalDate = LocalDate.of(2026, 10, 11)

fun at(date: String, time: String): Instant = LocalDateTime.parse("${date}T$time").atZone(IST).toInstant()

fun at(date: LocalDate, hour: Int, minute: Int = 0): Instant = date.atTime(hour, minute).atZone(IST).toInstant()

// Starts 23:00 the evening before `date`. With stages: 20% deep, 25% REM, 50% light, 5% awake.
fun night(date: LocalDate, hours: Double, stages: Boolean = false): SleepSession {
    val start = at(date.minusDays(1), 23)
    val total = (hours * 3600).toLong()
    val end = start.plusSeconds(total)
    if (!stages) return SleepSession(start, end, emptyList())
    var t = start
    val parts = listOf(StageType.DEEP to 0.20, StageType.REM to 0.25, StageType.LIGHT to 0.50, StageType.AWAKE to 0.05)
    val list = parts.map { (type, f) ->
        val e = t.plusSeconds((total * f).toLong())
        SleepStage(t, e, type).also { t = e }
    }
    return SleepSession(start, end, list)
}

fun day(
    date: LocalDate,
    hrv: Double? = null,
    rhr: Double? = null,
    sleepHours: Double? = null,
    stages: Boolean = false,
) = HealthSnapshot(
    sleep = listOfNotNull(sleepHours?.let { night(date, it, stages) }),
    hrv = listOfNotNull(hrv?.let { Sample(at(date, 5), it) }),
    restingHr = listOfNotNull(rhr?.let { Sample(at(date, 7), it) }),
)

// `days` days of identical data ending the day before `today`.
fun history(
    today: LocalDate,
    days: Int,
    hrv: Double? = 40.0,
    rhr: Double? = 60.0,
    sleepHours: Double? = 8.0,
    stages: Boolean = false,
): HealthSnapshot = (1..days)
    .map { day(today.minusDays(it.toLong()), hrv, rhr, sleepHours, stages) }
    .fold(HealthSnapshot()) { a, b -> a + b }

operator fun HealthSnapshot.plus(o: HealthSnapshot) = HealthSnapshot(
    sleep = sleep + o.sleep,
    hrv = hrv + o.hrv,
    restingHr = restingHr + o.restingHr,
    spo2 = spo2 + o.spo2,
    respiratoryRate = respiratoryRate + o.respiratoryRate,
    skinTempDelta = skinTempDelta + o.skinTempDelta,
    hourlySteps = hourlySteps + o.hourlySteps,
    dailyActivity = dailyActivity + o.dailyActivity,
    exercise = exercise + o.exercise,
    generic = generic + o.generic,
    sources = sources + o.sources,
)
```

```kotlin
package app.fitdash.metrics

import app.fitdash.IST
import app.fitdash.TODAY
import app.fitdash.health.Sample
import org.junit.Assert.assertEquals
import org.junit.Assert.assertNull
import org.junit.Test
import java.time.Instant

class BaselinesTest {
    @Test fun `median of odd, even and empty lists`() {
        assertEquals(2.0, median(listOf(3.0, 1.0, 2.0))!!, 0.0)
        assertEquals(2.5, median(listOf(4.0, 1.0, 3.0, 2.0))!!, 0.0)
        assertNull(median(emptyList()))
    }

    @Test fun `dailyMean buckets by local date not UTC`() {
        val samples = listOf(
            Sample(Instant.parse("2026-10-10T20:00:00Z"), 40.0), // 01:30 IST on 11 Oct
            Sample(Instant.parse("2026-10-11T01:00:00Z"), 50.0), // 06:30 IST on 11 Oct
        )
        assertEquals(mapOf(TODAY to 45.0), dailyMean(samples, IST))
    }

    @Test fun `dailyLast keeps the latest sample of the day`() {
        val samples = listOf(
            Sample(Instant.parse("2026-10-11T03:00:00Z"), 61.0),
            Sample(Instant.parse("2026-10-11T01:00:00Z"), 58.0),
        )
```

```kotlin
package app.fitdash.metrics

import app.fitdash.health.Sample
import java.time.LocalDate
import java.time.ZoneId

fun median(values: List<Double>): Double? {
    if (values.isEmpty()) return null
    val s = values.sorted()
    val mid = s.size / 2
    return if (s.size % 2 == 1) s[mid] else (s[mid - 1] + s[mid]) / 2
}

private fun byDate(samples: List<Sample>, zone: ZoneId) =
    samples.groupBy { it.time.atZone(zone).toLocalDate() }

fun dailyMean(samples: List<Sample>, zone: ZoneId): Map<LocalDate, Double> =
    byDate(samples, zone).mapValues { (_, v) -> v.map { it.value }.average() }

fun dailyLast(samples: List<Sample>, zone: ZoneId): Map<LocalDate, Double> =
    byDate(samples, zone).mapValues { (_, v) -> v.maxBy { it.time }.value }

fun dailySum(samples: List<Sample>, zone: ZoneId): Map<LocalDate, Double> =
    byDate(samples, zone).mapValues { (_, v) -> v.sumOf { it.value } }

fun baseline(daily: Map<LocalDate, Double>, date: LocalDate): Double? =
    median(daily.filterKeys { it < date && it >= date.minusDays(Tuning.BASELINE_DAYS) }.values.toList())
```

```kotlin
package app.fitdash.metrics

import app.fitdash.health.SleepSession
import app.fitdash.health.SleepStage
import app.fitdash.health.StageType
import java.time.Duration
import java.time.LocalDate
import java.time.ZoneId
import kotlin.math.min
import kotlin.math.roundToInt

data class SleepSummary(
    val asleep: Duration,
    val deep: Duration,
    val rem: Duration,
    val light: Duration,
    val awake: Duration,
    val hasStages: Boolean,
    val score: Int,
    val stages: List<SleepStage>,
)

fun nightEnding(date: LocalDate, sessions: List<SleepSession>, zone: ZoneId): SleepSession? =
    sessions
        .filter { it.end.atZone(zone).toLocalDate() == date }
        .maxByOrNull { Duration.between(it.start, it.end) }

private fun SleepSession.total(vararg types: StageType): Duration =
    stages.filter { it.type in types }.fold(Duration.ZERO) { acc, s -> acc + Duration.between(s.start, s.end) }

private fun SleepSession.hasStages() =
    stages.any { it.type == StageType.DEEP || it.type == StageType.REM || it.type == StageType.LIGHT }

fun asleepDuration(night: SleepSession): Duration =
    if (night.stages.isEmpty()) Duration.between(night.start, night.end)
    else night.total(StageType.LIGHT, StageType.DEEP, StageType.REM, StageType.SLEEPING)

fun deepRemShare(night: SleepSession): Double? {
    if (!night.hasStages()) return null
    val asleep = asleepDuration(night).seconds.toDouble()
    if (asleep <= 0) return null
    return night.total(StageType.DEEP, StageType.REM).seconds / asleep
}

fun baselineDeepRemShare(date: LocalDate, sessions: List<SleepSession>, zone: ZoneId): Double? =
    median((1..Tuning.BASELINE_DAYS).mapNotNull { nightEnding(date.minusDays(it), sessions, zone)?.let(::deepRemShare) })

fun sleepScore(night: SleepSession, baselineShare: Double?): Int {
    val hours = asleepDuration(night).seconds / 3600.0
    var score = min(hours / Tuning.SLEEP_TARGET_HOURS, 1.0) * 100
    val share = deepRemShare(night)
    if (share != null && baselineShare != null) {
        score += ((share - baselineShare) * 100).coerceIn(-Tuning.STAGE_ADJUST_MAX, Tuning.STAGE_ADJUST_MAX)
    }
    return score.roundToInt().coerceIn(0, 100)
}

fun summarizeSleep(date: LocalDate, sessions: List<SleepSession>, zone: ZoneId): SleepSummary? {
    val night = nightEnding(date, sessions, zone) ?: return null
    return SleepSummary(
        asleep = asleepDuration(night),
        deep = night.total(StageType.DEEP),
        rem = night.total(StageType.REM),
        light = night.total(StageType.LIGHT),
        awake = night.total(StageType.AWAKE),
        hasStages = night.hasStages(),
        score = sleepScore(night, baselineDeepRemShare(date, sessions, zone)),
        stages = night.stages,
    )
}
```

```kotlin
package app.fitdash.metrics

import app.fitdash.health.HealthSnapshot
import java.time.LocalDate
import java.time.ZoneId
import kotlin.math.roundToInt

enum class Band { RECOVER, STEADY, PRIMED }

enum class Component { HRV, RESTING_HR, SLEEP }

sealed interface ReadinessResult {
    data object NoData : ReadinessResult
    data class Calibrating(val nights: Int) : ReadinessResult
    data class Ready(val score: Int, val band: Band, val used: Set<Component>) : ReadinessResult
}

fun band(score: Int): Band = when {
    score < Tuning.BAND_STEADY -> Band.RECOVER
    score < Tuning.BAND_PRIMED -> Band.STEADY
    else -> Band.PRIMED
}

fun hrvComponent(today: Double, baseline: Double): Double {
    val pct = (today / baseline - 1) * 100
    val slope = if (pct >= 0) (100 - Tuning.AT_BASELINE) / Tuning.HRV_PCT_SPAN
    else (Tuning.AT_BASELINE - Tuning.FLOOR) / Tuning.HRV_PCT_SPAN
    return (Tuning.AT_BASELINE + pct * slope).coerceIn(0.0, 100.0)
}

fun rhrComponent(today: Double, baseline: Double): Double {
    val delta = today - baseline
    val slope = if (delta <= 0) (100 - Tuning.AT_BASELINE) / Tuning.RHR_BPM_SPAN
    else (Tuning.AT_BASELINE - Tuning.FLOOR) / Tuning.RHR_BPM_SPAN
    return (Tuning.AT_BASELINE - delta * slope).coerceIn(0.0, 100.0)
}

private val WEIGHTS = mapOf(
    Component.HRV to Tuning.WEIGHT_HRV,
    Component.RESTING_HR to Tuning.WEIGHT_RHR,
    Component.SLEEP to Tuning.WEIGHT_SLEEP,
)

fun readiness(snapshot: HealthSnapshot, date: LocalDate, zone: ZoneId): ReadinessResult {
    val hrv = dailyMean(snapshot.hrv, zone)
    val rhr = dailyLast(snapshot.restingHr, zone)
    val night = nightEnding(date, snapshot.sleep, zone)

    if (hrv[date] == null && rhr[date] == null && night == null) return ReadinessResult.NoData

    val nights = (1..Tuning.BASELINE_DAYS).map { date.minusDays(it) }.count { d ->
        hrv[d] != null || rhr[d] != null || nightEnding(d, snapshot.sleep, zone) != null
    }
    if (nights < Tuning.MIN_NIGHTS) return ReadinessResult.Calibrating(nights)

    val parts = buildMap {
        val hrvToday = hrv[date]
        val hrvBase = baseline(hrv, date)
        if (hrvToday != null && hrvBase != null && hrvBase > 0) put(Component.HRV, hrvComponent(hrvToday, hrvBase))
        val rhrToday = rhr[date]
        val rhrBase = baseline(rhr, date)
        if (rhrToday != null && rhrBase != null) put(Component.RESTING_HR, rhrComponent(rhrToday, rhrBase))
        if (night != null) put(Component.SLEEP, sleepScore(night, baselineDeepRemShare(date, snapshot.sleep, zone)).toDouble())
    }
    if (parts.isEmpty()) return ReadinessResult.NoData

    val total = parts.keys.sumOf { WEIGHTS.getValue(it) }
    val score = (parts.entries.sumOf { (k, v) -> v * WEIGHTS.getValue(k) } / total).roundToInt()
    return ReadinessResult.Ready(score, band(score), parts.keys)
}
```

```kotlin
package app.fitdash.metrics

import app.fitdash.health.HealthSnapshot
import app.fitdash.health.Sample
import java.time.Duration
import java.time.LocalDate
import java.time.ZoneId
import kotlin.math.roundToInt

data class HeartSummary(
    val hrv: Double?,
    val hrvBaseline: Double?,
    val restingHr: Double?,
    val restingHrBaseline: Double?,
    val hrvTrend: List<Double>,
)

data class VitalReading(val label: String, val unit: String, val value: Double, val baseline: Double?)

data class ActivitySummary(
    val date: LocalDate,
    val steps: Long,
    val goalPercent: Int,
    val hourly: List<Long>,
    val activeMinutes: Long,
    val distanceKm: Double,
    val kcal: Double,
)

fun heartSummary(snapshot: HealthSnapshot, date: LocalDate, zone: ZoneId): HeartSummary? {
    val hrv = dailyMean(snapshot.hrv, zone)
    val rhr = dailyLast(snapshot.restingHr, zone)
    if (hrv[date] == null && rhr[date] == null) return null
    val from = date.minusDays(Tuning.TREND_DAYS - 1)
    return HeartSummary(
        hrv = hrv[date],
        hrvBaseline = baseline(hrv, date),
        restingHr = rhr[date],
        restingHrBaseline = baseline(rhr, date),
        hrvTrend = hrv.filterKeys { it in from..date }.toSortedMap().values.toList(),
    )
}

fun vitals(snapshot: HealthSnapshot, date: LocalDate, zone: ZoneId): List<VitalReading> =
    listOf(
        Triple("SpO₂", "%", snapshot.spo2),
        Triple("Respiratory rate", "br/min", snapshot.respiratoryRate),
        Triple("Skin temperature", "°C", snapshot.skinTempDelta),
    ).mapNotNull { (label, unit, samples: List<Sample>) ->
        val daily = dailyMean(samples, zone)
        daily[date]?.let { VitalReading(label, unit, it, baseline(daily, date)) }
    }

fun activitySummary(snapshot: HealthSnapshot, date: LocalDate, zone: ZoneId): ActivitySummary? {
    val day = snapshot.dailyActivity.firstOrNull { it.date == date }
    val buckets = snapshot.hourlySteps.filter { it.start.atZone(zone).toLocalDate() == date }
    if (day == null && buckets.isEmpty()) return null
    val hourly = List(24) { h -> buckets.filter { it.start.atZone(zone).hour == h }.sumOf { it.steps } }
    val steps = day?.steps ?: hourly.sum()
    val active = snapshot.exercise
        .filter { it.start.atZone(zone).toLocalDate() == date }
        .sumOf { Duration.between(it.start, it.end).toMinutes() }
    return ActivitySummary(
        date = date,
        steps = steps,
        goalPercent = (steps * 100.0 / Tuning.STEP_GOAL).roundToInt(),
        hourly = hourly,
        activeMinutes = active,
        distanceKm = (day?.distanceMeters ?: 0.0) / 1000,
        kcal = day?.kcal ?: 0.0,
    )
}
```

```kotlin
package app.fitdash.metrics

import app.fitdash.health.GenericSeries
import app.fitdash.health.HealthSnapshot
import app.fitdash.health.SourceStatus
import java.time.LocalDate
import java.time.ZonedDateTime

enum class HeroMode { READINESS, ACTIVITY }

enum class CardKind { SLEEP, HEART, VITALS, ACTIVITY, READINESS_COMPACT, WEEK, GENERIC, SOURCES }

data class WeekDay(val date: LocalDate, val score: Int?)

data class TodayData(
    val hero: HeroMode,
    val date: LocalDate,
    val readiness: ReadinessResult,
    val sleep: SleepSummary?,
    val heart: HeartSummary?,
    val vitals: List<VitalReading>,
    val activity: ActivitySummary?,
    val week: List<WeekDay>,
    val generic: List<GenericSeries>,
    val sources: List<SourceStatus>,
    val cards: List<CardKind>,
)

private val MORNING = listOf(
    CardKind.SLEEP, CardKind.HEART, CardKind.VITALS, CardKind.ACTIVITY, CardKind.WEEK, CardKind.GENERIC, CardKind.SOURCES,
)
private val EVENING = listOf(
    CardKind.ACTIVITY, CardKind.READINESS_COMPACT, CardKind.SLEEP, CardKind.HEART, CardKind.VITALS,
    CardKind.WEEK, CardKind.GENERIC, CardKind.SOURCES,
)

fun buildToday(snapshot: HealthSnapshot, now: ZonedDateTime): TodayData {
    val zone = now.zone
    val date = now.toLocalDate()
    val evening = now.hour >= Tuning.EVENING_HOUR
    val readiness = readiness(snapshot, date, zone)
    val sleep = summarizeSleep(date, snapshot.sleep, zone)
    val heart = heartSummary(snapshot, date, zone)
    val vitals = vitals(snapshot, date, zone)
    val activity = activitySummary(snapshot, if (evening) date else date.minusDays(1), zone)
    val week = (6L downTo 0L).map { d ->
        val day = date.minusDays(d)
        WeekDay(day, (readiness(snapshot, day, zone) as? ReadinessResult.Ready)?.score)
    }
    val generic = snapshot.generic.filter { it.points.isNotEmpty() }

    val available = mapOf(
        CardKind.SLEEP to (sleep != null),
        CardKind.HEART to (heart != null),
        CardKind.VITALS to vitals.isNotEmpty(),
        CardKind.ACTIVITY to (activity != null),
        CardKind.READINESS_COMPACT to (readiness is ReadinessResult.Ready),
        CardKind.WEEK to week.any { it.score != null },
        CardKind.GENERIC to generic.isNotEmpty(),
        CardKind.SOURCES to true,
    )

    return TodayData(
        hero = if (evening) HeroMode.ACTIVITY else HeroMode.READINESS,
        date = date,
        readiness = readiness,
        sleep = sleep,
        heart = heart,
        vitals = vitals,
        activity = activity,
        week = week,
        generic = generic,
        sources = snapshot.sources,
        cards = (if (evening) EVENING else MORNING).filter { available.getValue(it) },
    )
}
```

- [ ] **Step 3: Write the reader**

Steps, distance and calories come from Health Connect's aggregate API, which removes duplicates when both the phone and the Fitbit write steps. The hourly buckets use a `LocalDateTime` range so they line up with local hours (IST is a half-hour offset from UTC).

`app/src/main/java/app/fitdash/health/HealthReader.kt`:
```kotlin
package app.fitdash.health

import android.content.Context
import androidx.health.connect.client.HealthConnectClient
import androidx.health.connect.client.aggregate.AggregateMetric
import androidx.health.connect.client.permission.HealthPermission
import androidx.health.connect.client.records.DistanceRecord
import androidx.health.connect.client.records.ExerciseSessionRecord
import androidx.health.connect.client.records.HeartRateVariabilityRmssdRecord
import androidx.health.connect.client.records.OxygenSaturationRecord
import androidx.health.connect.client.records.Record
import androidx.health.connect.client.records.RespiratoryRateRecord
import androidx.health.connect.client.records.RestingHeartRateRecord
import androidx.health.connect.client.records.SkinTemperatureRecord
import androidx.health.connect.client.records.SleepSessionRecord
import androidx.health.connect.client.records.StepsRecord
import androidx.health.connect.client.records.TotalCaloriesBurnedRecord
import androidx.health.connect.client.request.AggregateGroupByDurationRequest
import androidx.health.connect.client.request.AggregateGroupByPeriodRequest
import androidx.health.connect.client.request.ReadRecordsRequest
import androidx.health.connect.client.time.TimeRangeFilter
import app.fitdash.metrics.Tuning
import app.fitdash.metrics.dailySum
import java.time.Duration
import java.time.Period
import java.time.ZonedDateTime
import kotlin.coroutines.cancellation.CancellationException
import kotlin.reflect.KClass

class HealthReader(private val context: Context) : HealthSource {
    private val client by lazy { HealthConnectClient.getOrCreate(context) }

    override val allPermissions: Set<String> =
        ALL_TYPES.map { HealthPermission.getReadPermission(it.type) }.toSet()

    override fun availability() = when (HealthConnectClient.getSdkStatus(context)) {
        HealthConnectClient.SDK_AVAILABLE -> Availability.AVAILABLE
        HealthConnectClient.SDK_UNAVAILABLE_PROVIDER_UPDATE_REQUIRED -> Availability.NEEDS_UPDATE
        else -> Availability.NOT_INSTALLED
    }

    override suspend fun grantedPermissions(): Set<String> = client.permissionController.getGrantedPermissions()

    override suspend fun read(now: ZonedDateTime): HealthSnapshot {
        val granted = grantedPermissions()
        fun can(type: KClass<out Record>) = HealthPermission.getReadPermission(type) in granted

        val start = now.toLocalDate().minusDays(Tuning.BASELINE_DAYS).atStartOfDay(now.zone)
        val range = TimeRangeFilter.between(start.toInstant(), now.toInstant())

        val records = mutableMapOf<KClass<out Record>, List<Record>>()
        val sources = ALL_TYPES.map { info ->
            val list = if (can(info.type)) readAllOrEmpty(info.type, range) else emptyList()
            records[info.type] = list
            SourceStatus(info.label, can(info.type), list.isNotEmpty(), list.map { it.metadata.dataOrigin.packageName }.toSet())
        }

        val hourly = if (can(StepsRecord::class)) {
            client.aggregateGroupByDuration(
                AggregateGroupByDurationRequest(
                    metrics = setOf(StepsRecord.COUNT_TOTAL),
                    timeRangeFilter = TimeRangeFilter.between(
                        now.toLocalDate().minusDays(1).atStartOfDay(),
                        now.toLocalDateTime(),
                    ),
                    timeRangeSlicer = Duration.ofHours(1),
                ),
            ).map { HourBucket(it.startTime, it.result[StepsRecord.COUNT_TOTAL] ?: 0L) }
        } else emptyList()

        val metrics = buildSet<AggregateMetric<*>> {
            if (can(StepsRecord::class)) add(StepsRecord.COUNT_TOTAL)
            if (can(DistanceRecord::class)) add(DistanceRecord.DISTANCE_TOTAL)
            if (can(TotalCaloriesBurnedRecord::class)) add(TotalCaloriesBurnedRecord.ENERGY_TOTAL)
        }
        val daily = if (metrics.isEmpty()) emptyList() else {
            client.aggregateGroupByPeriod(
                AggregateGroupByPeriodRequest(
                    metrics = metrics,
                    timeRangeFilter = TimeRangeFilter.between(start.toLocalDateTime(), now.toLocalDateTime()),
                    timeRangeSlicer = Period.ofDays(1),
                ),
            ).map {
                DayActivity(
                    date = it.startTime.toLocalDate(),
                    steps = it.result[StepsRecord.COUNT_TOTAL] ?: 0L,
                    distanceMeters = it.result[DistanceRecord.DISTANCE_TOTAL]?.inMeters ?: 0.0,
                    kcal = it.result[TotalCaloriesBurnedRecord.ENERGY_TOTAL]?.inKilocalories ?: 0.0,
                )
            }.filter { it.steps > 0 || it.distanceMeters > 0 }
        }

        val generic = GENERIC_TYPES.mapNotNull { g ->
            val points = records[g.type].orEmpty().mapNotNull(g::sample).sortedBy { it.time }
            val shown = if (g.perDay) {
                dailySum(points, now.zone).toSortedMap().map { (d, v) -> Sample(d.atStartOfDay(now.zone).toInstant(), v) }
            } else points
            if (shown.isEmpty()) null else GenericSeries(g.label, g.unit, shown)
        }

        return HealthSnapshot(
            sleep = records.of<SleepSessionRecord>().map { s ->
                SleepSession(s.startTime, s.endTime, s.stages.mapNotNull { st ->
                    stageType(st.stage)?.let { SleepStage(st.startTime, st.endTime, it) }
                })
            },
            hrv = records.of<HeartRateVariabilityRmssdRecord>().map { Sample(it.time, it.heartRateVariabilityMillis) },
            restingHr = records.of<RestingHeartRateRecord>().map { Sample(it.time, it.beatsPerMinute.toDouble()) },
            spo2 = records.of<OxygenSaturationRecord>().map { Sample(it.time, it.percentage.value) },
            respiratoryRate = records.of<RespiratoryRateRecord>().map { Sample(it.time, it.rate) },
            skinTempDelta = records.of<SkinTemperatureRecord>().flatMap { r -> r.deltas.map { Sample(it.time, it.delta.inCelsius) } },
            hourlySteps = hourly,
            dailyActivity = daily,
            exercise = records.of<ExerciseSessionRecord>().map { Interval(it.startTime, it.endTime) },
            generic = generic,
            sources = sources,
        )
    }

    // One type failing (e.g. skin temperature unsupported on this device) must not hide the rest.
    private suspend fun readAllOrEmpty(type: KClass<out Record>, range: TimeRangeFilter): List<Record> = try {
        val out = mutableListOf<Record>()
        var token: String? = null
        do {
            @Suppress("UNCHECKED_CAST")
            val res = client.readRecords(
                ReadRecordsRequest(recordType = type as KClass<Record>, timeRangeFilter = range, pageSize = 5000, pageToken = token),
            )
            out += res.records
            token = res.pageToken
        } while (token != null)
        out
    } catch (e: CancellationException) {
        throw e
    } catch (e: Exception) {
        emptyList()
    }
}

private inline fun <reified T : Record> Map<KClass<out Record>, List<Record>>.of(): List<T> =
    this[T::class].orEmpty().filterIsInstance<T>()

private fun stageType(stage: Int): StageType? = when (stage) {
    SleepSessionRecord.STAGE_TYPE_AWAKE,
    SleepSessionRecord.STAGE_TYPE_AWAKE_IN_BED,
    SleepSessionRecord.STAGE_TYPE_OUT_OF_BED -> StageType.AWAKE
    SleepSessionRecord.STAGE_TYPE_LIGHT -> StageType.LIGHT
    SleepSessionRecord.STAGE_TYPE_DEEP -> StageType.DEEP
    SleepSessionRecord.STAGE_TYPE_REM -> StageType.REM
    SleepSessionRecord.STAGE_TYPE_SLEEPING -> StageType.SLEEPING
    else -> null
}
```

```kotlin
package app.fitdash.ui.theme

import androidx.compose.ui.graphics.Color
import kotlin.math.roundToInt

private data class Stop(val at: Int, val r: Int, val g: Int, val b: Int)

private val STOPS = listOf(Stop(0, 229, 72, 77), Stop(50, 245, 176, 65), Stop(100, 61, 220, 151))

fun scoreColor(score: Int): Color {
    val s = score.coerceIn(0, 100)
    val (lo, hi) = if (s <= 50) STOPS[0] to STOPS[1] else STOPS[1] to STOPS[2]
    val t = (s - lo.at) / (hi.at - lo.at).toFloat()
    fun mix(a: Int, b: Int) = (a + (b - a) * t).roundToInt()
    return Color(mix(lo.r, hi.r), mix(lo.g, hi.g), mix(lo.b, hi.b))
}
```

```kotlin
@Composable
fun Orb(score: Int?, modifier: Modifier = Modifier, content: @Composable () -> Unit) {
    val target = score?.let(::scoreColor) ?: Palette.Calibrating
    val color by animateColorAsState(target, tween(1800), label = "orbColour")
    val transition = rememberInfiniteTransition(label = "orb")
    val breath = breathMillis(score ?: 50)
    val scale by transition.animateFloat(
        initialValue = 0.95f,
        targetValue = 1.05f,
        animationSpec = infiniteRepeatable(tween(breath / 2, easing = FastOutSlowInEasing), RepeatMode.Reverse),
        label = "breathe",
    )
    val phase by transition.animateFloat(
        initialValue = 0f,
        targetValue = (2 * PI).toFloat(),
        animationSpec = infiniteRepeatable(tween(9000, easing = LinearEasing)),
        label = "morph",
    )
    val highlight = lerp(color, Color.White, 0.55f)
    val onOrb = if (target.luminance() > 0.45f) Color(0xFF0B1A14) else Color.White

    Box(modifier.size(220.dp), contentAlignment = Alignment.Center) {
        Canvas(Modifier.size(220.dp).graphicsLayer { scaleX = scale; scaleY = scale }) {
            drawPath(
                blobPath(size, phase, 0.45f),
                Brush.radialGradient(
                    listOf(highlight, color, lerp(color, Color.Black, 0.45f)),
                    center = Offset(size.width * 0.38f, size.height * 0.38f),
                    radius = size.minDimension * 0.6f,
                ),
            )
            drawPath(
                blobPath(size, -phase, 0.38f),
                Brush.radialGradient(
                    listOf(highlight.copy(alpha = 0.7f), Color.Transparent),
                    center = Offset(size.width * 0.6f, size.height * 0.6f),
                    radius = size.minDimension * 0.45f,
                ),
                blendMode = BlendMode.Screen,
            )
        }
        CompositionLocalProvider(LocalContentColor provides onOrb) { content() }
    }
}

private fun blobPath(size: Size, phase: Float, radiusFraction: Float): Path {
    val c = Offset(size.width / 2, size.height / 2)
    val base = size.minDimension * radiusFraction
    val n = 8
    val pts = List(n) { i ->
        val a = i * 2f * PI.toFloat() / n
        val r = base * (1 + 0.06f * sin(phase + i * 1.7f) + 0.04f * cos(2 * phase - i))
        Offset(c.x + r * cos(a), c.y + r * sin(a))
    }
    return Path().apply {
        moveTo(pts[0].x, pts[0].y)
        for (i in 0 until n) {
            val p0 = pts[(i - 1 + n) % n]
            val p1 = pts[i]
            val p2 = pts[(i + 1) % n]
            val p3 = pts[(i + 2) % n]
            cubicTo(
                p1.x + (p2.x - p0.x) / 6, p1.y + (p2.y - p0.y) / 6,
                p2.x - (p3.x - p1.x) / 6, p2.y - (p3.y - p1.y) / 6,
                p2.x, p2.y,
            )
        }
        close()
    }
}
```

```kotlin
@Composable
fun TrendLine(values: List<Double>, color: Color, modifier: Modifier = Modifier) {
    val progress = rememberDrawProgress()
    Canvas(modifier) {
        if (values.size < 2) return@Canvas
        val lo = values.min()
        val span = (values.max() - lo).takeIf { it > 0 } ?: 1.0
        val pad = 3.dp.toPx()
        val path = Path().apply {
            values.forEachIndexed { i, v ->
                val x = i * size.width / (values.size - 1)
                val y = pad + (size.height - 2 * pad) * (1 - ((v - lo) / span).toFloat())
                if (i == 0) moveTo(x, y) else lineTo(x, y)
            }

        val partial = Path()
        measure.getSegment(0f, measure.length * progress, partial, true)
```

```kotlin
package app.fitdash.ui.today

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import app.fitdash.health.Availability
import app.fitdash.health.HealthSource
import app.fitdash.metrics.TodayData
import app.fitdash.metrics.buildToday
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.launch
import java.time.ZonedDateTime
import kotlin.coroutines.cancellation.CancellationException

sealed interface TodayUiState {
    data object Loading : TodayUiState
    data class NeedsHealthConnect(val update: Boolean) : TodayUiState
    data object NeedsPermission : TodayUiState
    data object NoData : TodayUiState
    data object Failed : TodayUiState
    data class Ready(val data: TodayData, val refreshing: Boolean = false, val error: Boolean = false) : TodayUiState
}

class TodayViewModel(
    private val source: HealthSource,
    private val clock: () -> ZonedDateTime = { ZonedDateTime.now() },
) : ViewModel() {
    private val _state = MutableStateFlow<TodayUiState>(TodayUiState.Loading)
    val state: StateFlow<TodayUiState> = _state

    val permissions: Set<String> get() = source.allPermissions

    fun load() {
        viewModelScope.launch {
            when (source.availability()) {
                Availability.NOT_INSTALLED -> {
                    _state.value = TodayUiState.NeedsHealthConnect(update = false)
                    return@launch
                }
                Availability.NEEDS_UPDATE -> {
                    _state.value = TodayUiState.NeedsHealthConnect(update = true)
                    return@launch
                }
                Availability.AVAILABLE -> Unit
            }
            val previous = _state.value as? TodayUiState.Ready
            if (previous != null) _state.value = previous.copy(refreshing = true)
            _state.value = try {
                if (source.grantedPermissions().none { it in source.allPermissions }) {
                    TodayUiState.NeedsPermission
                } else {
                    val snapshot = source.read(clock())
                    if (snapshot.sources.none { it.hasData }) TodayUiState.NoData
                    else TodayUiState.Ready(buildToday(snapshot, clock()))
                }
            } catch (e: CancellationException) {
                throw e
            } catch (e: Exception) {
                previous?.copy(refreshing = false, error = true) ?: TodayUiState.Failed
            }
        }
    }
}
```

```kotlin
        val plan = listOf(
            StageType.LIGHT to 20, StageType.DEEP to 40, StageType.LIGHT to 30, StageType.REM to 25, StageType.AWAKE to 10,
            StageType.LIGHT to 45, StageType.DEEP to 40, StageType.REM to 35, StageType.LIGHT to 50, StageType.REM to 37,
        )
        var t = start
        val stages = plan.map { (type, min) -> val e = t.plusSeconds(min * 60L); SleepStage(t, e, type).also { t = e } }
        return SleepSession(start, t, stages)
    }

    private val snapshot by lazy {
        val days = (0..13).map { today.minusDays(it.toLong()) }
        HealthSnapshot(
            sleep = days.map { stagedNight(at(it.minusDays(1), 23, 10)) },
            hrv = days.mapIndexed { i, d -> Sample(at(d, 5), if (i == 0) 48.0 else 40.0 + i % 5) },
            restingHr = days.mapIndexed { i, d -> Sample(at(d, 7), if (i == 0) 58.0 else 60.0 + i % 3) },
            spo2 = days.map { Sample(at(it, 4), 96.0) },
            respiratoryRate = days.map { Sample(at(it, 4), 14.5) },
            hourlySteps = hourly.mapIndexed { h, s -> HourBucket(at(today, h), s.toLong()) },
            dailyActivity = listOf(
                DayActivity(today.minusDays(1), 5760, 4300.0, 1820.0),
                DayActivity(today, 8240, 6100.0, 2140.0),
            ),
            exercise = listOf(Interval(at(today, 18), at(today, 18, 46))),
            generic = listOf(GenericSeries("Weight", "kg", days.reversed().mapIndexed { i, d -> Sample(at(d, 8), 72.4 - i * 0.05) })),
            sources = listOf(
                SourceStatus("Sleep", true, true, setOf("com.fitbit.FitbitMobile")),
                SourceStatus("Blood glucose", true, false, emptySet()),
                SourceStatus("Weight", false, false, emptySet()),
            ),
        )
    }

    fun today(hour: Int, minute: Int = 0): TodayData = buildToday(snapshot, today.atTime(hour, minute).atZone(zone))
}
```

```kotlin
@Composable
fun TodayScreen(state: TodayUiState.Ready, onRefresh: () -> Unit) {
    val data = state.data
    val list = rememberLazyListState()
    val collapseDistance = with(LocalDensity.current) { 240.dp.toPx() }
    val collapse by remember {
        derivedStateOf {
            if (list.firstVisibleItemIndex > 0) 1f
            else (list.firstVisibleItemScrollOffset / collapseDistance).coerceIn(0f, 1f)
        }
    }

    PullToRefreshBox(
        isRefreshing = state.refreshing,
        onRefresh = onRefresh,
        modifier = Modifier.fillMaxSize().background(Palette.Background),
    ) {
        LazyColumn(
            state = list,
            contentPadding = WindowInsets.systemBars.asPaddingValues(),
            verticalArrangement = Arrangement.spacedBy(12.dp),
        ) {
            item(key = "hero") {
                Hero(
                    data,
                    Modifier.graphicsLayer {
                        val t = collapse
                        translationY = if (list.firstVisibleItemIndex == 0) list.firstVisibleItemScrollOffset * 0.35f else 0f
                        scaleX = 1 - 0.45f * t
                        scaleY = 1 - 0.45f * t
                        alpha = 1 - t
                    },
                )
            }
            if (state.error) item(key = "error") { ErrorBanner(onRefresh) }
            items(data.cards, key = { it.name }) { kind -> RevealOnEnter { TodayCard(kind, data) } }
            item(key = "end") {

                    color = Palette.Faint,
                    textAlign = TextAlign.Center,
                    modifier = Modifier.fillMaxWidth().padding(top = 8.dp, bottom = 30.dp),

            }
        }
        MiniHeader(data, visible = collapse > 0.75f)
    }
}
```

```kotlin
        setContent { FitdashTheme { App() } }
    }
}

private const val HEALTH_CONNECT_STORE =
    "market://details?id=com.google.android.apps.healthdata&url=healthconnect%3A%2F%2Fonboarding"

@Composable
private fun App() {
    val context = LocalContext.current
    val vm: TodayViewModel = viewModel { TodayViewModel(HealthReader(context.applicationContext)) }
    val state by vm.state.collectAsStateWithLifecycle()
    val askPermissions = rememberLauncherForActivityResult(PermissionController.createRequestPermissionResultContract()) { vm.load() }

    LifecycleResumeEffect(Unit) {
        vm.load()
        onPauseOrDispose { }
    }

    when (val s = state) {
        TodayUiState.Loading -> LoadingScreen()
        is TodayUiState.NeedsHealthConnect -> MessageScreen(
            title = if (s.update) "Update Health Connect" else "Install Health Connect",
            body = "fitdash reads your Fitbit data through Health Connect.",
            action = if (s.update) "Update" else "Install",
            onAction = {
                context.startActivity(Intent(Intent.ACTION_VIEW, Uri.parse(HEALTH_CONNECT_STORE)).setPackage("com.android.vending"))
            },
        )
        TodayUiState.NeedsPermission -> MessageScreen(
            title = "Welcome to fitdash",
            body = "Allow read access in Health Connect. Nothing leaves your phone.",
            action = "Grant access",
            onAction = { askPermissions.launch(vm.permissions) },
        )
        TodayUiState.NoData -> MessageScreen(
            title = "No data yet",
            body = "In the Fitbit app, turn on Health Connect sync, then come back.",
            action = "Check again",
            onAction = vm::load,
        )
        TodayUiState.Failed -> MessageScreen(
            title = "Couldn't read Health Connect",
            body = "Something went wrong reading your data.",
            action = "Retry",
            onAction = vm::load,
        )
        is TodayUiState.Ready -> TodayScreen(s, onRefresh = vm::load)
    }
}
```
