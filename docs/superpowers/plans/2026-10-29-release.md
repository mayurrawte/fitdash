# fitdash release implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship name, dark mode, a Log tab, score chips, journal tags with correlations, sleep debt, weekly review on Today, a morning alert, a day timeline and CSV export in one release on the `redesign` branch.

**Architecture:** Pure metrics in `metrics/` with JUnit tests first; app-private state in `settings/` (`SettingsStore` for scalars, a new `JournalStore` JSON file for tags and nutrition entries); Compose UI reuses the stage 1 components (`StripCard`, `StatTile`, `HeroCard`, `RowGroup`, `SectionCard`, `ListRow`, `SegmentedControl`) and `Palette`/`Type`/`Motion` tokens. Health Connect writes go through `HealthSource`.

**Tech Stack:** Kotlin, Jetpack Compose, Material 3, Glance, WorkManager, Health Connect client, JUnit 4. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-29-fitdash-release-design.md` (read it first; this plan argues from it).

## Global Constraints

- Verify every task with `JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home ./gradlew :app:testGithubDebugUnitTest :app:lintGithubDebug :app:assembleGithubDebug` (all pass, lint has no errors). Call this "the verification command".
- Install on the Pixel with `adb install -r app/build/outputs/apk/github/debug/app-github-debug.apk` where a step says so.
- Metrics code stays pure (no Android imports). Tests use `app/src/test/java/app/fitdash/Fixtures.kt` (`TODAY`, `IST`, `day`, `history`, `night`, `at`).
- Every colour goes through `Palette` or `LocalTheme.current`; no `Color(0xFF…)` in `ui/` outside `Themes.kt` and `Palette.Sun`.
- No new `_underscore` helpers, no docstrings, no comments that restate code. Copy is British English, sentence case.
- Journal tags never go to Health Connect.
- Commit after every task with the message given. One pull request at the end.
- Where a UI step says "preview", add it to `PagerScreen.kt` next to the existing `TodayFull` style previews using `PreviewData`.

## Review Focus

1. **A name with spaces or emoji** must render in the greeting and the avatar takes the first grapheme, not a surrogate half (Task 1 test).
2. **Theme set to DARK with the system in light** must draw dark, and status bar icons must go light (Task 2 device step).
3. **A tag toggled on a past date** must persist under that date, not today (Task 6 test).
4. **Recovery with only one input used** must show exactly one chip and no empty pills (Task 7 test).
5. **Correlations with fewer than 5 tagged or 5 untagged days** must not appear, even when 10 tags exist in total (Task 9 test).
