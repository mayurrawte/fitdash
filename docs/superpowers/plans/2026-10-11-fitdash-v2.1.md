# fitdash v2.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Premium Ultrahuman-style restyle with five themes, a day picker, Settings & About with Buy-me-a-coffee, deltas, naps, Week/Month trends, estimated resting HR, share-day image, and a GitHub Pages site.

**Architecture:** Metrics gain goals, a selected date, previous-day scores, naps, a 30-day trend and estimated resting HR (Task 1, pure Kotlin, full code). The theme becomes data (`ThemeTokens`) provided through a CompositionLocal; `Palette`/`Type` become theme-backed composable getters so existing call sites keep their names (Task 2). The ViewModel keeps the last snapshot and rebuilds `TodayData` when the date or settings change without re-reading Health Connect. UI tasks (3–5) restyle components and pages to match the HTML mockups, which are the visual source of truth.

**Tech Stack:** as v2, plus bundled fonts (already committed in `bb17490`: `res/font/inter_{extralight,light,regular,medium}.ttf`, `res/font/jetbrains_mono_{regular,medium}.ttf`), Material 3 `DatePicker`, `SharedPreferences`, `FileProvider`.

## Global Constraints

- Gradle: `JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home ./gradlew --offline …`
- **Fonts:** Inter for text and numbers. JetBrains Mono, UPPERCASE with 0.08em tracking, for labels, units, status words, nav labels and dates. Big numbers use Inter weight 200–300 with −0.03em tracking.
- **No emoji in the UI.** Line icons only: 1.7 px stroke, round caps.
- **Status words:**
  - OPTIMAL (score ≥ 85 or range good side)
  - GOOD (≥ 70 or in range)
  - FAIR (≥ 50)
  - NEEDS ATTENTION (< 50 or range bad side)

  Colours are theme good, good, warn and bad respectively.
- **Themes:** TEAL (default), PASTEL, TECHNO, GRAPHITE, SUNRISE, with the exact tokens in Task 2.
- **Day picker window:** the last 30 days. Suggestions appear only on today.
- **Estimated resting HR:**
  - **Primary:** the lowest 30-minute rolling mean of heart-rate samples inside that night's main sleep, using at least 3 samples spanning at least 15 minutes.
  - **Fallback:** the 10th percentile of that day's samples, and only when there are at least 30 of them.
  - **Precedence:** recorded resting HR always wins.
  - **Label:** estimated values are tagged EST.
- **Settings:**
  - theme
  - step goal (default 9,000, step 500)
  - sleep goal (default 8 h, step 0.5)
  - km or miles

  All settings live in `SharedPreferences` named `fitdash`.
- **Support URL:** `https://buymeacoffee.com/thepsygeek`. GitHub URL: `https://github.com/mayurrawte/fitdash`.
- **Commit messages:** plain, with no AI attribution trailer.

## Review Focus

1. **Switching days or settings must not re-read Health Connect.** It rebuilds from the cached snapshot. Pinned in Task 2 (`selecting a date rebuilds without reading again`).
2. **Pastel is a light theme.** System-bar icons must turn dark and every text colour must come from the theme. Hard-coded `Color.White` text would vanish. This is verified on the device in Task 6.
3. **A past date** must not show today's suggestions or today's steps. Pinned in Task 1 (`a past date shows that day without suggestions`).
4. **A day with a recorded resting HR** must never be overwritten by an estimate. Pinned in Task 1 (`recorded resting HR wins and estimates are flagged`).
5. **The share image** must render off-screen at 1080×1350 regardless of scroll position or theme. This is verified on the device in Task 6.

```kotlin
package app.fitdash.metrics

import app.fitdash.health.HealthSnapshot
import app.fitdash.health.Sample
import app.fitdash.health.SleepSession
import java.time.Duration
import java.time.LocalDate
import java.time.ZoneId

fun lowestRollingMean(samples: List<Sample>, window: Duration): Double? {
    val s = samples.sortedBy { it.time }
    var best: Double? = null
    var j = 0
    var sum = 0.0
    for (i in s.indices) {
        val end = s[i].time.plus(window)
        while (j < s.size && !s[j].time.isAfter(end)) {
            sum += s[j].value
            j++
        }
        val count = j - i
        if (count >= Tuning.MIN_WINDOW_SAMPLES && Duration.between(s[i].time, s[j - 1].time) >= window.dividedBy(2)) {
            val mean = sum / count
            if (best == null || mean < best) best = mean
        }
        sum -= s[i].value
    }
    return best
}

fun estimateRestingHr(heartRate: List<Sample>, night: SleepSession?, date: LocalDate, zone: ZoneId): Double? {
    if (night != null) {
        val inNight = heartRate.filter { !it.time.isBefore(night.start) && !it.time.isAfter(night.end) }
        lowestRollingMean(inNight, Duration.ofMinutes(Tuning.RHR_WINDOW_MINUTES))?.let { return it }
    }
    val day = heartRate.filter { it.time.atZone(zone).toLocalDate() == date }.map { it.value }.sorted()
    if (day.size < Tuning.MIN_HR_SAMPLES) return null
    return percentile(day, 0.10)
}

fun withEstimatedRestingHr(snapshot: HealthSnapshot, zone: ZoneId, today: LocalDate): HealthSnapshot {
    if (snapshot.heartRate.isEmpty()) return snapshot
    val recorded = dailyLast(snapshot.restingHr, zone).keys
    val byDate = snapshot.heartRate.groupBy { it.time.atZone(zone).toLocalDate() }
    val added = mutableListOf<Sample>()
    val dates = mutableSetOf<LocalDate>()
    for (offset in 0..Tuning.BASELINE_DAYS) {
        val d = today.minusDays(offset)
        if (d in recorded) continue
        val hr = byDate[d].orEmpty() + byDate[d.minusDays(1)].orEmpty()
        estimateRestingHr(hr, nightEnding(d, snapshot.sleep, zone), d, zone)?.let {
            added += Sample(d.atTime(12, 0).atZone(zone).toInstant(), it)
            dates += d
        }
    }
    return snapshot.copy(restingHr = snapshot.restingHr + added, estimatedRestingHrDates = dates)
}
```

```kotlin
enum class Status { OPTIMAL, GOOD, FAIR, ATTENTION }

    RangeStatus.BAD_SIDE -> Status.ATTENTION
```

```kotlin
data class DayScores(val sleep: Int?, val readiness: Int?, val movement: Int?)

data class DayTrend(val date: LocalDate, val recovery: Int?, val sleepScore: Int?, val steps: Long?, val restingHr: Double?, val hrv: Double?)

fun buildToday(snapshot: HealthSnapshot, now: ZonedDateTime, date: LocalDate = now.toLocalDate(), goals: Goals = Goals()): TodayData {
    val zone = now.zone
    val snap = withEstimatedRestingHr(snapshot, zone, now.toLocalDate())
    val isToday = date == now.toLocalDate()
    val readiness = readiness(snap, date, zone, goals)
    val sleep = summarizeSleep(date, snap.sleep, zone, goals.sleepHours, snap.heartRate)
    val heart = heartSummary(snap, date, zone)
    val activity = activitySummary(snap, date, zone, goals.steps)
    val hrvDaily = dailyMean(snap.hrv, zone)
    val rhrDaily = dailyLast(snap.restingHr, zone)
    val trend = (Tuning.BASELINE_DAYS - 1 downTo 0L).map { date.minusDays(it) }.map { d ->
        DayTrend(
            date = d,
            recovery = (readiness(snap, d, zone, goals) as? ReadinessResult.Ready)?.score,
            sleepScore = summarizeSleep(d, snap.sleep, zone, goals.sleepHours)?.score,
            steps = stepsOn(snap, d, zone),
            restingHr = rhrDaily[d],
            hrv = hrvDaily[d],
        )
    }
    val prev = date.minusDays(1)
    val week = trend.takeLast(Tuning.WEEK_DAYS.toInt())
    return TodayData(
        date = date,
        isToday = isToday,
        goals = goals,
        readiness = readiness,
        sleep = sleep,
        heart = heart,
        vitals = vitals(snap, date, zone),
        activity = activity,
        movementScore = activity?.goalPercent?.coerceAtMost(100),
        readinessWeek = week.map { WeekDay(it.date, it.recovery) },
        sleepWeek = week.map { d ->
            val s = summarizeSleep(d.date, snap.sleep, zone, goals.sleepHours)
            SleepDay(d.date, s?.asleep?.let { it.seconds / 3600.0 }, s?.score)
        },
        activityWeek = week.map { d ->
            val a = snap.dailyActivity.firstOrNull { it.date == d.date }
            ActivityDay(d.date, d.steps, a?.distanceMeters?.div(1000), a?.kcal)
        },
        suggestions = if (isToday) suggestions(readiness, sleep, heart, activity, now.hour, goals.steps) else emptyList(),
        generic = snap.generic.filter { it.points.isNotEmpty() },
        sources = snap.sources,
        naps = napsEnding(date, snap.sleep, zone),
        previous = DayScores(
            summarizeSleep(prev, snap.sleep, zone, goals.sleepHours)?.score,
            trend.getOrNull(trend.size - 2)?.recovery,
            activitySummary(snap, prev, zone, goals.steps)?.goalPercent?.coerceAtMost(100),
        ),
        restingHrEstimated = date in snap.estimatedRestingHrDates,
        trend = trend,
        daysWithData = (snap.sleep.map { it.end.atZone(zone).toLocalDate() } +
            snap.dailyActivity.filter { it.steps > 0 }.map { it.date } +
            snap.hourlySteps.filter { it.steps > 0 }.map { it.start.atZone(zone).toLocalDate() }).toSet(),
    )
}
```

```kotlin
package app.fitdash.settings

import android.content.Context
import app.fitdash.ui.theme.ThemeId
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow

data class Settings(val theme: ThemeId = ThemeId.TEAL, val stepGoal: Int = 9000, val sleepHours: Double = 8.0, val miles: Boolean = false)

class SettingsStore(context: Context) {
    private val prefs = context.getSharedPreferences("fitdash", Context.MODE_PRIVATE)
    private val _flow = MutableStateFlow(read())
    val flow: StateFlow<Settings> = _flow

    private fun read() = Settings(
        theme = runCatching { ThemeId.valueOf(prefs.getString("theme", null) ?: "TEAL") }.getOrDefault(ThemeId.TEAL),
        stepGoal = prefs.getInt("stepGoal", 9000),
        sleepHours = prefs.getFloat("sleepHours", 8f).toDouble(),
        miles = prefs.getBoolean("miles", false),
    )

    fun update(change: (Settings) -> Settings) {
        val s = change(_flow.value)
        prefs.edit().putString("theme", s.theme.name).putInt("stepGoal", s.stepGoal)
            .putFloat("sleepHours", s.sleepHours.toFloat()).putBoolean("miles", s.miles).apply()
        _flow.value = s
    }
}
```
